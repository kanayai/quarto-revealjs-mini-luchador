# Quarto Revealjs Mini Luchador theme

A [Quarto](https://quarto.org) extension for authoring mini-luchador / children's-book-styled Reveal.js presentations.

Inspired by [quarto-revealjs-cinco-de-mayo](https://github.com/EmilHvitfeldt/quarto-revealjs-cinco-de-mayo) by Emil Hvitfeldt, restyled around a chibi vector-sticker luchador mascot.

## Installation

To start a new presentation:

``` bash
quarto use template kanayai/quarto-revealjs-mini-luchador
```

## Build the presentation

``` bash
quarto render mydocument.qmd
```
